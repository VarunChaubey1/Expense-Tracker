Expense Tracker App

A simple command-line based Expense Tracker built using Python. This application helps users record their daily expenses, view all transactions, and calculate total spending.

Features
Add new expenses with:
Date
Category
Description
Amount
View all recorded expenses
Calculate total expenses
Menu-driven interface
Easy to understand and beginner-friendly Python project
Technologies Used
Python 3
Lists
Dictionaries
Loops
Conditional Statements
User Input Handling
